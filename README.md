# Alinhavo — gestão simples para confecções

Protótipo navegável (front-end) de um sistema de gestão para confecções: produção, oficinas de costura, almoxarifado, custo real da peça, vendas/CRM (curva ABC), financeiro, cronograma de coleções e equipe.

Site estático (HTML, CSS e JavaScript puro), sem build. Os dados são fictícios e o que o visitante altera fica salvo apenas no navegador dele.

Para rodar localmente: abra `index.html` ou rode `python -m http.server` nesta pasta.
